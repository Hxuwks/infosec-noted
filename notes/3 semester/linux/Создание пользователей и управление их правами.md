# Управление пользователями
## **Создание пользователей**

Для создания пользователя используется команда `useradd`.

```bash
useradd alice
```

Эта команда создаст пользователя `alice` со стандартными параметрами:
- Создаст домашнюю директорию `/home/alice` (если не отключено опцией).
- Скопирует файлы из `/etc/skel` (шаблон оболочки) в домашнюю директорию.
- Назначит пользователю его **первичную (primary) группу** с таким же именем (`alice`).

**Часто используемые опции:**
- `-m` (`--create-home`): Создать домашнюю директорию (актуально, если в настройках по умолчанию это отключено).
- `-s /bin/bash`: Задать командную оболочку пользователя (например, `/bin/bash`, `/bin/zsh`, `/sbin/nologin`).
- `-g group`: Указать первичную группу (по умолчанию — группа с именем пользователя).
- `-G group1,group2`: Добавить пользователя в дополнительные (вторичные) группы.
- `-c "Alice Cooper"`: Добавить комментарий (обычно полное имя пользователя).

**Пример с опциями:**

```bash
useradd -m -s /bin/bash -c "Alice Cooper" -G developers,sales alice
```

После создания пользователя **обязательно нужно установить пароль** командой `passwd`:

```bash
passwd alice
```

---

## **Изменение свойств пользователя**

Для изменения уже созданного пользователя используется команда `usermod`. Она использует те же опции, что и `useradd`.

```bash
usermod -aG sudo alice     # Добавить пользователя alice в группу sudo (для прав администратора)
usermod -s /bin/zsh alice  # Изменить оболочку пользователя на zsh
usermod -L alice           # Заблокировать (LOCK) учетную запись пользователя
usermod -U alice           # Разблокировать (UNLOCK) учетную запись
```

**Важно:** Опция `-aG` (append to Groups) **добавляет** пользователя в новые группы, не трогая старые. Без `-a` пользователь будет удален из всех групп, не указанных в текущей команде.

---

## **Удаление пользователей**

Удаление выполняется командой `userdel`.

```bash
userdel alice     # Удалит пользователя, но оставит его домашнюю директорию.
userdel -r alice  # Удалит пользователя вместе с его домашней директорией 
```

**Внимание:** Опция `-r` безвозвратно удаляет все личные файлы пользователя.

---
## **Создание групп**

Для создания группы используется команда `groupadd`.

```bash
groupadd developers  # Создаст группу с именем 'developers'
```

**GID (Group ID):** Каждой группе назначается уникальный числовой идентификатор. Он назначается автоматически, но его можно задать вручную с помощью опции `-g` (например, `-g 1010`).

---
## **Изменение групп**

Команда `groupmod` позволяет изменить имя группы или её GID.

```bash
groupmod -n devs developers  # Переименовать группу 'developers' в 'devs'
groupmod -g 1020 devs        # Изменить GID группы 'devs' на 1020
```
**Важно:** Изменение GID может сломать права доступа к файлам, принадлежащим этой группе. Необходимо будет обновить владельца файлов с помощью `chown`.

---
## **Управление членством в группах**

Основной инструмент — команда `gpasswd`. Она также позволяет задать пароль для группы (используется с `newgrp`, как описано в вашем конспекте).
```bash
gpasswd -a alice developers  # Добавить пользователя alice в группу developers
gpasswd -d alice developers  # Удалить пользователя alice из группы developers
gpasswd -M alice,bob,carl developers  # Задать СПИСОК членов группы (старые будут удалены!)
```

**Ключевое различие:**
- `usermod -aG` — управление со стороны пользователя (какие группы у него есть).
- `gpasswd -a/-d/-M` — управление со стороны группы (кто в ней состоит).

---
## **Удаление групп**

Удаление группы выполняется командой `groupdel`.

```bash
groupdel developers
```

**Ограничение:** Нельзя удалить группу, которая является **первичной (primary)** для какого-либо существующего пользователя. Сначала нужно изменить первичную группу пользователя или удалить самого пользователя.

---
## **Просмотр информации**

- `id [username]` — показать UID, GID и группы, в которых состоит пользователь.
- `groups [username]` — показать список групп пользователя.
- `getent group groupname` — показать информацию о группе и её членах.
- Просмотр файлов конфигурации:
    - `/etc/passwd` — информация о пользователях (логин, UID, GID, оболочка).
    - `/etc/group` — информация о группах.
    - `/etc/shadow` — зашифрованные пароли пользователей (только для `root`).

**Ключевое правило:** Для выполнения всех этих команд (кроме `id` и `groups` для себя) требуются **права суперпользователя (`root`)**. Используйте `sudo` перед командой, если вы работаете не из-под `root`.

---
## Основные способы просмотра пользователей:
- **Список всех пользователей:**  
    `cat /etc/passwd` — показывает детальную информацию (UID, GID, домашняя директория).
- **Активные пользователи (кто сейчас в системе):**  
    `who` — список залогиненных.  
    `w` — подробная информация, включая текущие процессы.  
    `users` — только имена залогиненных.
- **История входов:**  
    `last` — показывает историю входов/выходов.  
    `lastlog` — отображает время последнего входа всех пользователей.

# Управление правами

## Изменение владельца

Для изменения владельца используется команда `chown`, в которой мы указываем пользователя и файл, у которого мы меняем владельца на ранее указанного.

```shell
chown jxskj /home/accounts
```

В этой команде есть одна важная опция, которая встречается в большинстве команд. Опция `-R` позволяет рекурсивно задавать права доступа не только к самой директории но и к всему её содержимого. Команда `chown -R jxksj /home/accounts`, уже не просто передаст права директории `accounts`, но и всем её вложенным.

---

## Измнение владельца группы

Для изменения группы можно применить команду `chgrp`, либо же также использовать `chown`, которая также способна изменять группы. Приведем примеры изменения группы:

```shell
chgrp .sales /home/accounts #стандартное изменение группы
chown jxskj.code main.c #изменяем владельца на jxskj а группу на code. Также вместо точки между именем и группой можно ставить :
chown .code main.c #изменение группы без изменнеия пользователя. Также можно использовать :
```

Как и в случае с `chown`, здесь применима опция `-R` для рекурсивного изменения. Как писалось ранее, группой файла становится группа, в которой состоит пользователь. Но иногда он есть в нескольких группах и одна из них должна быть как "целевая".

```shell
╭─ jxskj@thinkpad ~
╰─❯ groups
jxskj wheel
╭─ jxskj@thinkpad ~
╰─❯ newgrp wheel
╭─ jxskj@thinkpad ~
╰─❯ groups      
wheel jxskj
```

Выше приведен пример изменения целевой группы. Это правило будет работать до первой перезагрузки или до первого выхода из системы. Чтобы пользователь мог выдвинуть группу как целевую он ОБЯЗАТЕЛЬНО должен быть её членом. Иначе оболочка потребует ввести пароль группы(его можно установить через команду `gpasswd)

## Права в linux

В linux у нас есть 3 основных права: read, write, execute. Рассотрим на что они влияют в отношении файлов и диреткорий.

|Права|файлы|директории|
|---|---|---|
|Read|прочитать содержимого файла|отобразить списка содержимого директории|
|Write|изменить содержание файла|создавать, удалять или задавать права на файлы|
|Execute|запустить файл как программу|перейти в директорию|

Для изменения прав используется команда `chmod`, в которой мы задаем права на директорию или файл. Права можно задать как в буквенном, так и в числовом формате. По умолчанию права идут в следующем порядке: user -> group -> other.

Разеберем как установить права в численном и буквенном значении:

- Read - `4` или `r`
- Write - `2` или `w`
- Execute - `1` или `x` Когда мы задаем права в числовом формате мы записываем трехзначное число, в котором каждая цифра явлется суммой прав для той или иной группы. Например:

```shell
chmod 755 /somefile
```

Даст макисмальные права для текущего пользователя, чтение и запуск для группы и `other`. Если же мы использует буквенный формат, то мы используем `+` и `-` для доступа или запрета на определенные права. Привдем пример нескольких команд для предоставления прав.

```shell
chmod +x /somefile #разрешения на запуск для всех
chmod go-rw secret.txt #запрет группе и остальным на чтение и запись
chmod a=r document.pdf #дать права всем только на чтение
chmod u=rwx,g=r file.txt # пользователю - всё, групепе только чтение

```

# Специальные права и acl

## Специальные права доступа (Special Permissions)

Стандартные права (rwx) дополняются тремя специальными битами. В числовом виде они записываются как четвертая (первая слева) цифра: например, `4755`.

**SUID (Set User ID) — 4000**
- **Для кого:** Только для исполняемых файлов.
- **Эффект:** Программа выполняется с правами **владельца** файла, а не пользователя, который её запустил.
- **Пример:** Команда `passwd`. Чтобы сменить пароль, нужно записать данные в `/etc/shadow`, куда есть доступ только у root. Благодаря SUID обычный пользователь может это сделать.
- **Символ:** `rws------` (буква **s** на месте **x** владельца).

**SGID (Set Group ID) — 2000**
- **Для файлов:** Программа выполняется с правами группы владельца.
- **Для директорий:** Самый частый сценарий. Все файлы, созданные внутри такой директории, автоматически получают ту же **группу**, что и у самой директории (а не основную группу пользователя).
- **Пример:** Общая папка для отдела разработки.
- **Символ:** `rwxrws---` (буква **s** на месте **x** группы).

**Sticky Bit (Липкий бит) — 1000**
- **Для директорий:** Запрещает удаление или переименование файлов внутри директории всем, кроме **владельца конкретного файла** или root.
- **Пример:** Папка `/tmp`. Все могут туда писать, но никто не может удалить чужой временный файл.
- **Символ:** `rwxrwxrwt` (буква **t** в конце).

---

Работа с acl происходит с помощью команды `setfacl`, которая имеет следующий синтаксис:
```bash 
setfacl [options] operation entity:entityname:permissions file
```
Также можно менять права через простой chmod, но acl предоавтляет больший функционал и широту для применения.
Рассмотрим опции и операции для `setfacl`, которые можно применять для управления правами:
- options : позволяет пр помощи опций управлять работы команды. Основные опции:
	- `-d` : устанавливает acl по умолчанию
	- `-k` : удаляет список acl по умолчанию
	- `-R` : рекурсивно применяет настройки acl
- operation : позволляет добавлять или удалять настройки ACL. Основные операции:
	- `--set` : используется для установки ACL. Она заменяет любой существующий ACL
	- `-m` : дополняет текущие настройки, без замены текущей
	- `-x` : удаляет текущий ACL
- entity и entity name : тип и имя объекта которые определяют для кого надо установить acl. Пользователь -  `u` и группа - `g`
- permissions : устанавливаемые разрешения
- file : имя файла или каталога, к которому необходимо принять изменения

---

После того, как основные опции пройдены, изучим примеры:

```bash
setfacl -m g:users:rwx /somedir
setfacl -d -m g:users:rwx,g:developers:rx /somedir
```

Для того чтобы получить права файла или каталога используем команду:

```bash
getfacl file
```
