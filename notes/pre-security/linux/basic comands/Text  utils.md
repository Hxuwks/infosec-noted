## cut

Утилита для вырезания из каждой строки файла (или входящего потока) определенных секций: столбцов по разделителю, отдельной позиции символов или байтов.

**Синтаксис:**

```bash
cut [опции] [файл]

```

### Основные флаги

* **Выбор режима извлечения (обязательно один из трёх):**
* `-f` (`--fields=LIST`) — выбор полей (столбцов), разделенных специальным символом (по умолчанию Табуляция).
* `-c` (`--characters=LIST`) — выбор конкретных символов по их порядковому номеру в строке.
* `-b` (`--bytes=LIST`) — выбор конкретных байтов в строке (актуально для ASCII или работы с бинарным содержимым).


* **Настройка разделителя и полей:**
* `-d "CHAR"` (`--delimiter=CHAR`) — задание символа-разделителя полей (используется только вместе с `-f`).
* `-s` (`--only-delimited`) — не выводить строки, которые **не содержат** указанный разделитель.
* `--complement` — инверсировать выбор: выводить всё, **кроме** указанных полей/символов.
* `--output-delimiter=STRING` — изменить символ-разделитель при выводе извлечённых данных.



> **Формат синтаксиса списков (LIST):**
> * `N` — только N-й элемент.
> * `N,M` — N-й и M-й элементы.
> * `N-M` — элементы с N по M включительно.
> * `N-` — от N-го элемента до конца строки.
> * `-M` — от начала строки до M-го элемента включительно.

---

### Практические примеры с разбором

```bash
cut -d: -f1,7 /etc/passwd

```

> **Что делает:** Использует двоеточие `:` в качестве разделителя (`-d:`) и извлекает первое и седьмое поля из файла `/etc/passwd`. На выходе вы получите список логинов пользователей и назначенные им командные оболочки (shell).

```bash
cut -d' ' -f2- --complement log.txt

```

> **Что делает:** Разбивает файл по пробелам (`-d' '`) и за счет ключа `--complement` выводит все поля, **кроме** начиная со второго и до конца (`-f2-`). В итоге команда выведет строго первое поле (например, только метку времени логирования).

```bash
head -n 5 /etc/shadow | cut -c 1-10

```

> **Что делает:** Берёт первые 5 строк и с помощью `-c 1-10` вырезает ровно первые 10 символов каждой строки независимо от разделителей.

```bash
grep -v "^#" config.conf | cut -d'=' -s -f2

```

> **Что делает:** Исключает комментарии, разбивает конфигурационный файл по знаку `=` и за счет `-s` игнорирует пустые строки или строки без `=`, выводя только значения параметров (второе поле `-f2`).

## sort

Утилита для сортировки строк в текстовых файлах или входящем потоке данных. Поддерживает алфавитную, числовую, версию-ориентированную сортировку и сортировку по нескольким колонкам.

**Синтаксис:**

```bash
sort [опции] [файл]

```

### Основные флаги

* **Тип сортировки:**
* `-n` (`--numeric-sort`) — числовая сортировка (сравнивает значения как числа, а не как строки: `2` идет до `10`).
* `-h` (`--human-numeric-sort`) — сортировка размерностей, понятных человеку (`2K`, `1M`, `3G`).
* `-V` (`--version-sort`) — естественная сортировка номеров версий (`v1.2`, `v1.2.1`, `v1.10`).
* `-r` (`--reverse`) — сортировка в обратном (убывающем) порядке.
* `-R` (`--random-sort`) — случайная перемешка строк (хэширование).


* **Управление столбцами и разделителями:**
* `-t CHAR` (`--field-separator=CHAR`) — символ-разделитель полей.
* `-k POS1[,POS2]` (`--key`) — сортировка по указанному столбцу (позиции).


* **Оптимизация и работа с выводом:**
* `-u` (`--unique`) — убрать дубликаты (оставить только уникальные строки после сортировки).
* `-o FILE` (`--output=FILE`) — записать результат непосредственно в файл (безопасно указывать тот же файл, что и на входе).
* `-c` (`--check`) — проверить, отсортирован ли файл, без вывода содержимого.



---

### Практические примеры с разбором

```bash
sort -t: -k3,3n /etc/passwd

```

> **Что делает:** Использует разделитель `:` (`-t:`), выбирает строго 3-й столбец UID (`-k3,3`) и выполняет по нему численный порядок (`n`). В результате учетные записи будут отсортированы строго по возрастанию их UID.

```bash
du -sh * | sort -h -r

```

> **Что делает:** `du -sh *` выводит размеры папок в человекочитаемом виде (`10M`, `2G`), а `sort -h -r` сортирует их по реальному объему от наибольшего к наименьшему (`-r`).

```bash
sort -u -o ips.txt ips.txt

```

> **Что делает:** Сортирует файл `ips.txt`, удаляет из него повторы (`-u`) и перезаписывает результат в тот же файл (`-o`), избегая повреждения данных (в отличие от `sort ips.txt > ips.txt`, который обнулит файл).

```bash
sort -k2,2 -k1,1r users.txt

```

> **Что делает:** Применяет составной ключ сортировки: сначала сортирует по второму столбцу в прямом алфавитном порядке (`-k2,2`), а при совпадении значений во втором столбце — сортирует по первому столбцу в обратном порядке (`-k1,1r`).

## uniq

Утилита для фильтрации или подсчета повторений смежных (идущих подряд) строк.

> **Важно:** `uniq` сравнивает **только соседние строки**. Чтобы найти все дубликаты во всём файле, входящие данные **обязательно нужно отсортировать** через `sort`.

**Синтаксис:**

```bash
uniq [опции] [входной_файл [выходной_файл]]

```

### Основные флаги

* **Режимы отбора строк:**
* `-c` (`--count`) — выводит количество повторений перед каждой найденной строкой.
* `-d` (`--repeated`) — выводить **только повторившиеся** строки (дубликаты).
* `-D` (`--all-repeated`[=delimiters]) — выводить все экземпляры повторяющихся строк.
* `-u` (`--unique`) — выводить **только уникальные** строки (которые встречались ровно 1 раз).
* `-i` (`--ignore-case`) — не учитывать регистр символов при сравнении.


* **Смещение и ограничение сравнения:**
* `-f N` (`--skip-fields=N`) — пропустить первые `N` полей (разделенных пробелами/табуляциями) перед сравнением.
* `-s N` (`--skip-chars=N`) — пропустить первые `N` символов перед сравнением.
* `-w N` (`--check-chars=N`) — сравнивать не всю строку, а только первые `N` символов.



---

### Практические примеры с разбором

```bash
cut -d' ' -f1 access.log | sort | uniq -c | sort -nr | head -n 10

```

> **Что делает:** Популярный конвейер аналитики. Извлекает IP-адреса из веб-лога, сортирует их для сгруппировывания, считает частоту каждого IP (`uniq -c`), сортирует полученную статистику по убыванию чисел (`sort -nr`) и выводит ТОП-10 активных адресов.

```bash
sort identifiers.txt | uniq -d

```

> **Что делает:** Находит и выводит список всех элементов, которые встречаются в файле `identifiers.txt` более одного раза.

```bash
uniq -f 1 -w 5 data.txt

```

> **Что делает:** При сравнении строк пропускает первое столбец-слово (`-f 1`) и проводит сравнение только по следующим 5 символам (`-w 5`).

## wc (Word Count)

Утилита для подсчета количества строк, слов, байтов и символов в файле или потоке ввода.

**Синтаксис:**

```bash
wc [опции] [файлы]

```

### Основные флаги

* `-l` (`--lines`) — подсчет количества символов новой строки (количество строк).
* `-w` (`--words`) — подсчет количества слов (последовательностей символов, разделенных пробельными символами).
* `-c` (`--bytes`) — подсчет количества байтов.
* `-m` (`--chars`) — подсчет количества символов (учитывает многобайтовые кодировки, такие как UTF-8).
* `-L` (`--max-line-length`) — вывод длины самой длинной строки в файле (в символах).

---

### Практические примеры с разбором

```bash
find /etc -type f -name "*.conf" | wc -l

```

> **Что делает:** Передаёт список найденных `.conf` файлов в `wc -l`, рассчитывая их общее количество.

```bash
wc -l -w -m document.txt

```

> **Что делает:** Выводит точную статистику по файлу: количество строк, количество слов и количество символов UTF-8.

```bash
ss -tulpn | grep "LISTEN" | wc -l

```

> **Что делает:** Подсчитывает количество сетевых служб, прослушивающих TCP/UDP порты в данный момент.

## Сравнительная и связующая матрица

| Утилита    | Назначение                           | Требует ли предварительной сортировки? | Типичный фрагмент пайплайна |          |
| ---------- | ------------------------------------ | -------------------------------------- | --------------------------- | -------- |
| **`cut`**  | Вырезка вертикальных колонок/срезов  | Нет                                    | `cut -d',' -f1`             |          |
| **`sort`** | Переупорядочивание строк по правилам | Нет (сам сортирует)                    | `sort -nk2`                 |          |
| **`uniq`** | Горизонтальная агрегация повторов    | **Да**                                 | `sort                       | uniq -c` |
| **`wc`**   | Метрики объема текста                | Нет                                    | `wc -l`                     |          |
