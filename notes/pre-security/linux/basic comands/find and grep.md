## find

Утилита для поиска файлов и каталогов в файловой системе по их метаданным (имени, размеру, правам, владельцу, времени модификации и т. д.). Выполняет реальный обход дерева каталогов в режиме реального времени.

**Синтаксис:**

```bash
find [путь] [критерии] [действия]

```

### Основные флаги и критерии поиска

* **По имени и типу:**
* `-name "pattern"` — поиск по имени с учетом регистра (поддерживает wildcards: `*`, `?`).
* `-iname "pattern"` — регистронезависимый поиск по имени.
* `-type t` — фильтрация по типу объекта:
	* `f` — обычный файл.
	* `d` — каталог.
	* `l` — символическая ссылка.
	* `s` — сокет.
	* `p` — FIFO (named pipe).

* `-maxdepth N` / `-mindepth N` — ограничение глубины рекурсивного обхода каталогов.


* **По размеру и времени:**
* `-size [+-]N[kMG]` — поиск по размеру (`+` больше, `-` меньше). Юниты: `k` (КБ), `M` (МБ), `G` (ГБ).
* `-mtime [+-]N` — время изменения содержимого в днях (`-7` — за последние 7 дней, `+30` — более 30 дней назад).
* `-mmin [+-]N` — время изменения содержимого в минутах.
* `-atime` / `-ctime` — время последнего доступа (access) / изменения метаданных (change).


* **По правам и владельцу:**
* `-user username` / `-group groupname` — поиск по владельцу или группе.
* `-perm mode` — поиск по точным правам доступа (например, `644`) или маске (`-4000` для SUID).


* **Логические операторы:**
* `-not` или `!` — инверсия условия (НЕ).
* `-a` — логическое И (применяется по умолчанию).
* `-o` — логическое ИЛИ.



### Действия над найденными объектами

* `-print` — вывод результатов в stdout (по умолчанию).
* `-delete` — удаление найденных объектов (не требует `-exec`).
* `-exec command {} \;` — выполнение команды для каждого найденного файла поочередно (`{}` заменяется путем к файлу).
* `-exec command {} +` — передача всех найденных файлов аргументами в одну команду (аналог пакетирования `xargs`).

---

### Практические примеры с разбором

```bash
find /var/log -type f -iname "*.log" -maxdepth 2

```

> **Что делает:** Ищет обычные файлы (`-type f`) в `/var/log`, имена которых заканчиваются на `.log` без учета регистра (`-iname`). Ограничивает поиск текущей директорией и одним уровнем вложенности (`-maxdepth 2`).

```bash
find /home/user -type f -size +100M -mtime -7

```

> **Что делает:** Находит в `/home/user` файлы размером строго больше 100 Мегабайт (`-size +100M`), содержимое которых редактировалось в течение последних 7 дней (`-mtime -7`).

```bash
find /var/tmp -type f -name "*.tmp" -exec rm -f {} +

```

> **Что делает:** Находит все временные файлы с расширением `.tmp` в `/var/tmp` и передает их списком команде `rm -f` (`-exec ... +`), удаляя их за один вызов процесса.

```bash
find . -type f ! -perm 644

```

> **Что делает:** Находит в текущей директории все файлы, права доступа на которые **не** равны `644` (чтение/запись для владельца, чтение для остальных).

## grep

Утилита для поиска строк, соответствующих заданному тексту или регулярному выражению, внутри файлов или во входящем потоке данных (stdin).

**Синтаксис:**

```bash
grep [опции] "шаблон" [файлы]

```

### Основные флаги

* **Управление совпадениями и выводом:**
* `-i` (`--ignore-case`) — игнорировать регистр символов.
* `-v` (`--invert-match`) — инверсировать поиск: выводить строки, **не** содержащие шаблон.
* `-n` (`--line-number`) — выводить номера строк в файле, где найдены совпадения.
* `-c` (`--count`) — выводить только количество совпавших строк вместо самих строк.
* `-w` (`--word-regexp`) — искать точное совпадение слова целиком (границы `\b`).
* `-x` (`--line-regexp`) — искать совпадение со всей строкой целиком.
* `-l` (`--files-with-matches`) — выводить только имена файлов, содержащих совпадение.
* `-L` (`--files-without-match`) — выводить имена файлов, в которых совпадений нет.


* **Рекурсия и контекст:**
* `-r` / `-R` — рекурсивный поиск по каталогам (`-R` переходит по символическим ссылкам).
* `-A N` (`--after-context`) — показать `N` строк **после** найденного совпадения.
* `-B N` (`--before-context`) — показать `N` строк **до** найденного совпадения.
* `-C N` (`--context`) — показать `N` строк **до и после** совпадения.


* **Режимы регулярных выражений:**
* `-E` (`--extended-regexp`) — использование расширенных регулярных выражений (ERE: `+`, `?`, `|`, `()`). Аналог утилиты `egrep`.
* `-P` (`--perl-regexp`) — использование регулярных выражений в стиле Perl (PCRE: `\d`, `\w`, `\s`, lookaround).
* `-F` (`--fixed-strings`) — трактовать шаблон как фиксированную строку, а не регулярку (ускоряет поиск). Аналог утилиты `fgrep`.



---

### Практические примеры с разбором

```bash
grep -rnI --exclude-dir={node_modules,.git} "API_KEY" /src

```

> **Что делает:** Ищет строку `"API_KEY"` рекурсивно (`-r`) в `/src`, с выводом номеров строк (`-n`), пропуская бинарные файлы (`-I`) и исключая из сканирования каталоги `node_modules` и `.git`.

```bash
grep -E -o "([0-9]{1,3}\.){3}[0-9]{1,3}" /var/log/auth.log

```

> **Что делает:** Использует расширенные регулярные выражения (`-E`) для поиска IPv4-адресов в `auth.log`. Флаг `-o` (`--only-matching`) заставляет `grep` выводить только сам найденный IP-адрес, а не всю строку целиком.

```bash
grep -i -C 3 "error" server.log

```

> **Что делает:** Находит слово `"error"` без учета регистра (`-i`) в файле `server.log` и выводит контекст: по 3 строки до и после каждой найденной строки (`-C 3`).

```bash
ps aux | grep -v "grep" | grep "nginx"

```

> **Что делает:** Фильтрует список запущенных процессов (`ps aux`), исключая сам процесс `grep` (`grep -v "grep"`), и находит строки с упоминанием процесса `nginx`.

## locate (plocate / mlocate)

Утилита для мгновенного поиска файлов по имени. В отличие от `find`, `locate` не сканирует диск напрямую, а запрашивает предварительно индексированную базу данных (обычно `/var/lib/mlocate/mlocate.db` или `/var/lib/plocate/plocate.db`).

> **Важно:** Файлы, созданные после последнего обновления базы данных, не будут найдены через `locate` до вызова команды обновления: `sudo updatedb`.

**Синтаксис:**

```bash
locate [опции] "шаблон"

```

### Основные флаги

* `-i` (`--ignore-case`) — поиск без учета регистра.
* `-b` (`--basename`) — искать совпадение шаблона только в имени файла, а не во всем пути (`/path/to/file`).
* `-c` (`--count`) — вывести только количество найденных записей.
* `-n N` (`--limit`) — ограничить вывод первым `N` результатами.
* `-e` (`--existing`) — выводить только те файлы, которые физически существуют в системе на данный момент (фильтрует удаленные файлы после последнего `updatedb`).
* `-r` (`--regexp`) — поиск с использованием базовых или расширенных регулярных выражений.

---

### Практические примеры с разбором

```bash
sudo updatedb && locate -i -b "nginx.conf"

```

> **Что делает:** Принудительно обновляет индексированную базу данных файловой системы (`updatedb`), затем находит все файлы, у которых само имя (базовое имя, `-b`), независимо от регистра (`-i`), равен `"nginx.conf"`.

```bash
locate -e -n 5 "*.py"

```

> **Что делает:** Ищет файлы с расширением `.py`, проверяет их текущее существование на диске (`-e`) и ограничивает вывод первыми 5 строками (`-n 5`).

## Сравнительная таблица утилит поиска

| Характеристика          | `find`                                                 | `grep`                                           | `locate`                              |
| ----------------------- | ------------------------------------------------------ | ------------------------------------------------ | ------------------------------------- |
| **Область поиска**      | Метаданные файлов / ФС                                 | Текст внутри файлов / stdin                      | Пути к файлам в базе данных           |
| **Скорость**            | Медленная (прямой обход диска)                         | Зависит от объема файлов                         | Мгновенная (чтение индекса)           |
| **Актуальность данных** | 100% (реальное время)                                  | 100% (реальное время)                            | Требует `updatedb`                    |
| **Основной сценарий**   | Поиск по размеру, дате, правам, с выполнением действий | Поиск логов, кода, регулярных выражений в тексте | Быстрый поиск где лежит файл по имени |
