Структура каталогов в Linux регламентируется стандартом **FHS (Filesystem Hierarchy Standard)**. Понимание назначения ключевых директорий критично для системного администрирования, управления правами и правильной разбивки диска на разделы.

---

## /home — Пользовательские данные

Предназначен для хранения личных файлов пользователей, индивидуальных настроек программ (dot-файлов) и рабочих окружений. Каждый пользователь имеет свой подкаталог (`/home/username`).

* **Особенности:**
* Единственное место в системе (кроме `/tmp`), где обычный пользователь имеет полные права на запись по умолчанию.
* Права доступа обычно ограничены схемой `700` (`drwx------`) или `750`, закрывая доступ другим пользователям.


* **Ключевые скрытые каталоги (Dotfiles):**
* `~/.config/` — стандартизированные пользовательские конфигурации приложений (XDG Base Directory specification).
* `~/.local/share/` — пользовательские данные приложений (история, плагины, локально установленные утилиты в `~/.local/bin`).
* `~/.cache/` — временные кеши программ (можно безопасно удалять).



```bash
# Просмотр размера домашних каталогов всех пользователей
du -sh /home/*

# Поиск "тяжелых" скрытых папок кеша у текущего пользователя
ncdu ~/.cache

```

## /etc — Конфигурационные файлы системы

Содержит **статические текстовые конфигурационные файлы** для настройки системы, сетевых служб и установленных программ.

* **Особенности:**
* В `/etc` **запрещено** хранить исполняемые бинарные файлы.
* Права на запись принадлежат исключительно `root`.
* Изменения в `/etc` напрямую меняют поведение демонов и ядра.



### Важнейшие подкаталоги и файлы

| Путь | Назначение |
| --- | --- |
| `/etc/passwd` | Учетные записи пользователей (UID, GID, shell, домашний каталог). |
| `/etc/shadow` | Зашифрованные хеши паролей пользователей (доступен только `root`). |
| `/etc/fstab` | Таблица точек монтирования файловых систем при загрузке. |
| `/etc/sudoers` | Правила делегирования прав `sudo` (редактируется только через `visudo`). |
| `/etc/systemd/system/` | Пользовательские unit-файлы инициализации Systemd. |
| `/etc/network/` или `/etc/netplan/` | Конфигурации сетевых интерфейсов. |
| `/etc/ssh/sshd_config` | Конфигурационный файл SSH-сервера. |

```bash
# Безопасная проверка синтаксиса перед перезапуском службы (пример SSH)
sshd -t -f /etc/ssh/sshd_config

# Создание бэкапа конфигурации с сохранением прав доступа
cp -p /etc/fstab /etc/fstab.bak

```

## /var — Динамические и изменяемые данные (Variable)

Содержит файлы, размер или содержимое которых постоянно меняется в процессе работы системы: логи, базы данных, очереди печати и почты, временные блокировки, кеш пакетного менеджера.

* **Особенности:**
* Часто выносится на **отдельный диск/раздел**. Если лог-файлы переполнят `/var`, основная система на `/` (root) продолжит функционировать.



### Ключевые подкаталоги

* `/var/log/` — системные и сервисные журналы (`syslog`, `auth.log`, `nginx/`, `journal/`).
* `/var/lib/` — состояние и базы данных приложений (данные Docker в `/var/lib/docker`, базы данных PostgreSQL/MySQL, базы пакетов `dpkg`/`pacman`).
* `/var/spool/` — очереди задач, ожидающих обработки (очереди печати CUPS, задания `cron`, почта).
* `/var/cache/` — сгенерированные кеши приложений и пакетных менеджеров (`/var/cache/apt/archives`).
* `/var/tmp/` — временные файлы, сохраняющиеся между перезагрузками (в отличие от `/tmp`, который часто очищается при старте или смонтирован в RAM через `tmpfs`).
* `/var/run` — симлинк на `/run`. Содержит runtime-данные: PID-файлы запущенных процессов и сокеты.

```bash
# Мониторинг заполнения каталогов в /var
du -h --max-depth=1 /var | sort -hr

# Очистка кеша пакетного менеджера APT для освобождения места
sudo apt-clean && sudo rm -rf /var/cache/apt/archives/*

```

## /opt — Стороннее автономное ПО (Optional)

Предназначен для установки **независимых сторонних проприетарных или вендорных программ**, которые поставляются монолитным пакетом и не входят в стандартный дистрибутив.

* **Особенности:**
* Программа устанавливается в собственный изолированный подкаталог: `/opt/app-name/`.
* Внутри `/opt/app-name/` приложение хранит свои собственные бинарники (`bin/`), библиотеки (`lib/`) и конфигурации.
* Примеры программ в `/opt`: Google Chrome, Zoom, JetBrains IDE, custom-инструменты сетевого анализа.



```bash
# Типичная структура сторонней утилиты в /opt
/opt/custom-app/
├── bin/
│   └── start-app
├── lib/
└── config/

# Для вызова из терминала бинарник симлинкают в /usr/local/bin
sudo ln -s /opt/custom-app/bin/start-app /usr/local/bin/start-app

```

## /usr — Системные ресурсы пользователя (User System Resources)

Крупнейший каталог системы. Содержит вторичный иерархический уровень с исполняемыми файлами, библиотеками и документацией, которыми управляет системный пакетный менеджер.

> **Современный контекст (UsrMerge):** В большинстве современных дистрибутивов (Debian/Ubuntu, Arch, Fedora) каталоги `/bin`, `/sbin`, `/lib` в корне системы являются символическими ссылками на соответствующие папки в `/usr` (`/usr/bin`, `/usr/sbin`, `/usr/lib`).

### Ключевые подкаталоги

* `/usr/bin/` — основные исполняемые файлы для всех пользователей (`ls`, `grep`, `python3`, `git`).
* `/usr/sbin/` — бинарные файлы системного администрирования, требующие прав root (`fdisk`, `iptables`, `ip`).
* `/usr/lib/` / `/usr/lib64/` — системные разделяемые библиотеки (`.so`-файлы) и модули.
* `/usr/share/` — архитектурно-независимые данные (мануалы `man`, локали, иконки, шрифты).
* `/usr/src/` — исходный код компонентов системы (например, исходники ядра и модули DKMS).
* `/usr/local/` — **локальная иерархия** для ПО, скомпилированного вручную из исходников (не отслеживается пакетным менеджером). Содержит свои собственные папки `/usr/local/bin`, `/usr/local/lib` и т.д.

```bash
# Проверка принадлежности бинарника из /usr пакетному менеджеру (Debian/Ubuntu)
dpkg -S /usr/bin/htop

# Проверка порядка поиска исполняемых файлов (приоритет у /usr/local/bin)
echo $PATH
# Вывод: /usr/local/bin:/usr/bin:/bin:...

```

## Сводная матрица сравнения

| Каталог     | Тип данных                         | Кто управляет / Изменяемость        | Вынос на отдельный раздел                       |
| ----------- | ---------------------------------- | ----------------------------------- | ----------------------------------------------- |
| **`/home`** | Пользовательские файлы и конфиги   | Пользователь / Постоянно меняются   | **Рекомендуется** (удобно при переустановке ОС) |
| **`/etc`**  | Текстовые конфигурации системы     | Администратор (`root`) / Статичные  | Нет (должен быть на корневом диске)             |
| **`/var`**  | Логи, БД, кеш, состояния сервисов  | Система и демоны / Высокая динамика | **Рекомендуется** (защита от переполнения `/`)  |
| **`/opt`**  | Стороннее автономное ПО            | Администратор / Редко               | Опционально                                     |
| **`/usr`**  | Бинарники, библиотеки дистрибутива | Пакетный менеджер (`apt`, `pacman`) | Опционально                                     |
